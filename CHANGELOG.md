# Changelog

## 0.1.0

- Initial release.
- Added vectorized ROR, PRR, IC, IC025, and IC975 calculations.
- Added validation for 2x2 contingency table columns.
- Added optional screening flags for ROR, PRR, and IC.
- Added short API aliases: `disp.ror`, `disp.prr`, `disp.ic`, and
  `disp.disproportionality`.
